// cheatsheet · hooks do Claude Code

Onde dá pra plugar uma decisão.

sessão e prompt
SessionStartstartup · resume · compactstdout vira contexto. Jev: qual contexto do projeto carregar.
UserPromptSubmitbloqueiaAntes do Claude ler o prompt. Jev: prompt vago? pede detalhe.
UserPromptExpansionbloqueiaQuando um /comando vira prompt.
InstructionsLoadedobservaCLAUDE.md ou .claude/rules carregado.
SessionEndobservaFim da sessão. Orçamento curto: 1,5 s.
ferramentas · matcher = nome da tool
PreToolUsebloqueiaallow · deny · ask · defer e updatedInput. Jev: comando arriscado?
PermissionRequestdecideNa hora do prompt de permissão: behavior allow/deny.
PostToolUsedevolveDepois do sucesso. updatedToolOutput troca o resultado.
PostToolUseFailuredevolveDepois da falha. Jev: flake ou bug de verdade?
PostToolBatchbloqueiaLote paralelo terminou, antes da próxima chamada ao modelo.
fim de turno e contexto
Stop · SubagentStopbloqueiablock faz continuar. Jev: terminou mesmo?
PreCompact · PostCompactmanual · autoPre pode barrar a compaction. Jev: vale compactar agora?
PreModelSwitchbloqueiaAntes de trocar de modelo: allow/deny/ask.
NotificationobservaPedido de permissão, ociosidade. Bom pra avisar no celular.
SubagentStart · StopFailureobservaSubagente nasce · turno morre por erro de API.
exit code
0 ok: stdout JSON é lido
2 bloqueia: stderr vai pro Claude
outro erro, mas a ação segue
"onFailure": "block" falha bloqueia
saída JSON
decision: "block" + reason
hookSpecificOutput.permissionDecision
hookSpecificOutput.additionalContext ≤ 10k chars
continue: false · systemMessage · stopReason
